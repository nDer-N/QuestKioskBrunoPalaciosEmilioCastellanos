**PROJECT 02**

**BRUNO PALACIOS CACHO & EMILIO CASTELLANOS CORTEZ**

The following project is a kiosk that allows students at the Universidad Panamericana to reserve a Vision Quest for a specific day, time, and duration. The version of Unity in which this project was developed is 6000.3.8f1.

The interface design is based directly on a prototype previously developed in Figma, which can be accessed via this link: [https\://www\.figma.com/proto/3V7NUAXiXzdv0FBKOEAUxt/PartialProject1?node-id=0-1\&t=M6X6AaWXUdXwB8rZ-1](https://www.figma.com/proto/3V7NUAXiXzdv0FBKOEAUxt/PartialProject1?node-id=0-1&t=M6X6AaWXUdXwB8rZ-1)

Setup Instructions

Download the release linked in the release section on the github repository. Once downloaded, run the .exe named QuestKioskBrunoPalaciosEmilioCastellanos. Once in, you could test Scenario A as it is. In order to test Scenario B, the user needs to manually book the entirety of the kits (all 6 of them) at a specific day and hour. Showing the Scenario B. 

The memory of the bookings will be persistent even with restarts of the .exe, so in order to reset all of the bookings, once inside the program click the **R** key on your keyboard and a Dev Panel should appear, with a button that says **RESET.** Once clicked, all of the booking history is **ERASED. This action cannot be undone.** 

To interact with the buttons, the user needs to click them with their mouse.
